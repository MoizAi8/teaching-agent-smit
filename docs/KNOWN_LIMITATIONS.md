# Remaining work

The current checkpoint is not a completed release. Hosted PostgreSQL, Vercel deployment and hosted end-to-end verification are blocked on production credentials. Comprehensive 250–300-scenario coverage has not been implemented.

Public topic catalog is an independent static learning outline, not a database-backed official course/enrollment system. Global private search has debounced owned-record matching; recent searches, advanced ranking and unified public/private destination search remain pending. Public inquiry launcher links to authenticated AI support; no anonymous model access.

Documents support TXT/Markdown only and bounded lexical retrieval, not PDF/DOCX parsing or learned embeddings. AI streaming/cancellation/regeneration, account deletion/reset/verification, admin role/content editing, notifications, quiz submission idempotency, persistent selected-view URLs, exportable screenshots/recordings and full light-theme QA remain incomplete. Records are shown in bounded lists; UI pagination and >200-message display require additional work. Source snippets are provided to the model but grounding correctness is not guaranteed.

Do not use for sensitive institutional records or advertise commercial production readiness.
